# 天眼查企业查询

1. 确认已安装并通过平台“连接”完成天眼查浏览器授权；缺少授权时使用平台入口，完成后重新查询。
2. 先发现当前 MCP 工具及参数 Schema。官方服务按当前账号权限公开搜索、企业画像、能力目录和调用入口；工具名称和参数以实际发现结果为准。
3. 用企业全称、统一社会信用代码或天眼查企业 ID 定位目标。多个同名结果时请用户选择，后续查询沿用选定的企业 ID。
4. 根据问题查能力目录，再调用已授权的工具。官方文档涵盖工商、股权、风险、知识产权、经营、历史及人员数据；各项操作以当前服务和账号权限为准。只查询回答所需的数据，批量请求控制在用户指定范围。
5. 回答标明企业名称、查询时间、数据来源、缺失项与返回的风险事实。无结果、无权限与接口失败分别说明；缺少数据不能解释为企业不存在或没有风险。

401 或过期时通过平台刷新或重新连接；权限、额度或限流错误如实提示并停止重复付费请求。参数通过结构化 MCP 调用传递。仅使用官方托管端点及平台提供的凭证，密钥不写入消息、文件或输出。Skill 不替代平台权限或一次性批准。

本修订验证了包结构、官方授权协议；尚无真实账号的 tools/list、企业数据 tools/call 或模型 Runtime 验收证据。官方 CLI 清单不能当作当前账号已可调用的工具清单。
