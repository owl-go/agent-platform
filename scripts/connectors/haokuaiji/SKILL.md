# 用友好会计

1. 确认选中的 Connector Installation 已连接到用户指定的好会计企业。未连接时引导用户进入连接器管理页和畅捷通官方 MCP 配置流程；账号凭证应通过平台加密授权入口保存。
2. 读取本连接器当前 MCP 工具目录及描述。公开指南只证明存在产品接入流程，本包没有固定或经过真实账号验证的业务工具名单。只在目录与 Schema 明确支持目标只读操作时继续；目录为空、缺少目标工具或权限拒绝时，说明具体缺失项。
3. 使用真实工具名与 Schema，确认企业、账套、会计期间和查询条件。若服务提供业务初始化、接口发现、文档读取等前置工具，按其描述依次调用。完成这些前置条件后再执行目标查询，不猜测接口路径、账套 ID 或参数。
4. 返回查询结果及账套、期间、数据来源。将本次查询成功与未执行的能力区分说明；数据为空时报告为空，不编造金额、税额或报表。

本修订仅指导只读查询。凭证新增、审核、删除、结账、反结账、发票开具和纳税申报尚无本包的真实验收证据；需要这些操作时先报告未验证，并要求连接器完成能力和批准策略审阅。本 Skill 不能代替平台的能力白名单或一次性批准。

认证失效时，用户应在官方 MCP 插件市场重新生成好会计配置，再更新自己的平台授权。企业／产品不匹配时核对官方 mcphub 的目标企业和主应用；不要切换到其他产品的 MCP 或使用其他人的凭证。

官方配置指南：https://cclaw.cjtmsp.com/docs/getting-started/mcp
