gh cache

Work with GitHub Actions caches.

Available commands

  gh cache delete

  gh cache list

Options

	-R, 
		--repo <[HOST/]OWNER/REPO>

	Select another repository using the [HOST/]OWNER/REPO format

Examples

$ gh cache list
$ gh cache delete --all
