gh run

List, view, and watch recent workflow runs from GitHub Actions.

Available commands

  gh run cancel

  gh run delete

  gh run download

  gh run list

  gh run rerun

  gh run view

  gh run watch

Options

	-R, 
		--repo <[HOST/]OWNER/REPO>

	Select another repository using the [HOST/]OWNER/REPO format
