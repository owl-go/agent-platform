gh repo deploy-key

Manage deploy keys in a repository

Available commands

  gh repo deploy-key add

  gh repo deploy-key delete

  gh repo deploy-key list

Options

	-R, 
		--repo <[HOST/]OWNER/REPO>

	Select another repository using the [HOST/]OWNER/REPO format

See also

  gh repo
