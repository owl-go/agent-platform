gh workflow

List, view, and run workflows in GitHub Actions.

Available commands

  gh workflow disable

  gh workflow enable

  gh workflow list

  gh workflow run

  gh workflow view

Options

	-R, 
		--repo <[HOST/]OWNER/REPO>

	Select another repository using the [HOST/]OWNER/REPO format
