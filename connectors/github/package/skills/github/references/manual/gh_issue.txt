gh issue

Work with GitHub issues.

General commands

  gh issue create

  gh issue list

  gh issue status

Targeted commands

  gh issue close

  gh issue comment

  gh issue delete

  gh issue develop

  gh issue edit

  gh issue lock

  gh issue pin

  gh issue reopen

  gh issue transfer

  gh issue unlock

  gh issue unpin

  gh issue view

Options

	-R, 
		--repo <[HOST/]OWNER/REPO>

	Select another repository using the [HOST/]OWNER/REPO format

Examples

$ gh issue list
$ gh issue create --label bug
$ gh issue view 123 --web
