# 北大法宝法规检索

1. 确认北大法宝 Connector Installation 已连接。未连接或收到 401 时，引导用户在连接器详情填写北大法宝 MCP 控制台的 Token；凭证由平台保管。
2. 读取已连接 MCP 的工具列表与 inputSchema。此修订连接官方法规语义服务，官方文档列出 `search_article` 和 `get_article`；以实际发现的工具名、必填字段和分页参数调用。
3. 法律问题先用 `search_article` 检索相关条文；指定法律名称和条号时用 `get_article` 查询原文。保留法条标题、条号、有效状态和服务返回的来源链接。
4. 以检索结果区分原文、解释和事实假设；缺少有效状态、时间或地域信息时明确说明。涉及重要决策时提示核对官方现行文本和完整事实。

本修订只提供法规语义检索与法条查询。司法案例、法规关键词库、引文校验和行政执法服务分别使用其他官方端点，不属于此修订。工具缺失时说明当前服务范围，不猜测其他端点。

403 时说明账号权限或服务开通状态需要核查；额度不足时引导用户查看控制台。调用超时仅进行有界重试。检索词会发送至北大法宝，并可能消耗其服务积分；只提交完成当前查询需要的内容。

官方接入文档：https://mcp.pkulaw.com/docs?doc=mcp-integration
