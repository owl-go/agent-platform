# 微信登录码缩短为四位数字

2026-10-06，用户明确保留网页展示码、向公众号发码、网页自动完成登录的现有流程，要求登录码改为四位数字。本决策仅取代 ADR-0044 的 60 位熵码格式；不增加公众号菜单、反向输码或其他登录步骤。

使用加密随机源均匀生成 `0000`–`9999`，按字符串保留前导零，只接受完整四位 ASCII 数字及首尾空白。登录码保持五分钟有效，与高熵的浏览器 Cookie、Attempt ID、OIDC code 和 PKCE 分离。

短码空间只有 10,000 个值，需要有界准入而不能沿用长码的猜测成本。PostgreSQL 唯一约束为原始有效期保留已分配码，OIDC handoff 缩短兑换期限也不提前释放；碰撞最多尝试 32 次，其他持久化错误立即失败。最多保留 100 个微信 Attempt。已认证公众号发送者五分钟最多提交 5 次新确认请求，全局一分钟最多 30 次，计数跨 API 副本原子共享；相同身份的已确认回调重试不消耗额度。存储失败或额度耗尽不确认身份，后者以加密被动回复提示稍后再试。

现有签名解密、公众号/应用绑定、版本校验、CAS 身份锁定、浏览器 Cookie、同源完成请求与 S256 PKCE 保持不变。发布前的长码 Attempt 显示过期恢复操作，不转换成短码。
