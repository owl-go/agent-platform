03 / 演示任务

把零散进展整理成周报

虚构教学资料
  • 订单完成联调，尚未验收
  • 支付测试指标改善，线上未知
  • 文案等反馈，移动端问题待复现
要求明确的结果
  1. 本周进展
  2. 风险与阻塞
  3. 下周行动表格

责任人、时间、依赖
缺失内容写“待确认”

04 / 系统演示 1

在会话里做好一次

提供材料→说明格式→核对事实→继续追问

先检查内容是否准确，再检查文字是否好看。

联调 ≠ 验收　测试指标 ≠ 线上结果　未知 ≠ 自行补齐
